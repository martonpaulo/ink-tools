# Changelog

The stable releases of each tool, newest first. Betas are prereleases and are not listed; the
[releases page](https://github.com/martonpaulo/ink-tools/releases) holds every build. Each tool
follows [`docs/product.md` › Product versioning](docs/product.md#product-versioning).

## Smart Pen 0.1.0 (2026-11-26)

- First stable release: Smart Shapes, Real-Time Text and Undo Conversion
  ([#305](https://github.com/martonpaulo/ink-tools/issues/305), [#373](https://github.com/martonpaulo/ink-tools/issues/373)).

## Device Link 0.1.0 (2026-11-26)

- First stable release: send a page or a selection to a LocalSend device on your own network
  ([#369](https://github.com/martonpaulo/ink-tools/issues/369), [#373](https://github.com/martonpaulo/ink-tools/issues/373)).
