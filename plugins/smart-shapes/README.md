# Smart Shapes

A Supernote plugin: draw a triangle, circle, square, rectangle or arrow and hold the pen still at
the end, as you do for the native Smart Straight Line. The stroke becomes a clean shape in your
current pen. Small figures, such as letters, always stay handwriting.

- Shapes: triangle, circle, square, rectangle, arrow.
- Smallest shape: 16 mm.
- Turn it on and off in Settings › Apps › Plugins.

Beta: built from Snap v0.9.0 (MIT, see [NOTICE.md](NOTICE.md)). See [AGENTS.md](AGENTS.md) for how
it works.
