# Plugin brief archive

The research, device tests and decisions of the first Ink Tools plugin, the picture plugin that
Word Lookup replaced on 2026-11-15 and that was removed from the repository on 2026-11-25
([#288](https://github.com/martonpaulo/ink-tools/issues/288)). Its code is gone; these notes stay
because the other plugins still rely on what they measured:

- [`brief.md`](brief.md): the SDK and PluginHost gotchas, the e-ink rules (section 8.4) and the
  measured device facts. A fact another plugin relies on belongs in
  [`docs/supernote.md`](../../supernote.md); move it there when you use it.
- [`device-tests.md`](device-tests.md) and `device-tests/`: the device rounds and their photos.
- [`security.md`](security.md): its answers to the application-security standard.
- [`research/`](research/): the search, ranking and distribution research behind the shared
  picture search (`packages/picture-search`).
- [`decisions.md`](decisions.md), [`product.md`](product.md),
  [`feature-defaults.md`](feature-defaults.md), [`answered-suspicions.md`](answered-suspicions.md)
  and [`cloud.md`](cloud.md): its own records, kept as history.

Nothing here is a current rule.
