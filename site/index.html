Tools for your Supernote tablet

Plugins and a tablet app that turn handwriting into shapes, text and pictures, sync your calendars and to-dos, and send pages to your phone, plus tools for the Mac. Not made by Ratta.

See the tools How to install, step by step

Tools

For people who use the tablet.

  • Plugin Working

    Smart Pen

    • Smart Shapes: draw a triangle, circle, square, rectangle or arrow and hold the pen still at the end; it becomes a clean shape, and letters stay handwriting.
    • Real-Time Text: while it is on, each handwritten word becomes typed text at its place, with no lasso; drawings stay handwriting.
    • Undo Conversion: brings the last converted word back as handwriting.
    • Gestures: a finger double or triple tap picks a pen, the eraser or the lasso, as you map it. (planned)

    Download Smart Pen Version 0.1.0

  • Plugin Beta

    Lasso Actions

    • Word Lookup: lasso a handwritten word, then Insert Sticker (a clean illustration), Insert Image (a photo), Choose Image (pick from the results), Insert Definition, Insert Summary (three sentences from Wikipedia) or Translate, one button per language pair, such as «Translate ES→PT».
    • Convert to Text: turn the whole lassoed handwriting into one text box.
    • Headings: Heading 1 to Heading 4 turn a lassoed line into a heading of that level at the left margin, across the page.
    • Collection: Add to Collection and Cut to Collection gather lasso selections; Paste Collection puts them together on another page.

    Download Lasso Actions Beta build 0.2.0-beta.33

  • Plugin Beta

    Image Editing

    • Enhance: make a lassoed picture readable on e-ink with one tap; Lighter and Darker adjust it.
    • Crop: draw a rectangle with the pen around the part to keep.
    • Erase: draw over the part to erase with the pen.
    • Remove background: keep the subject and drop what is behind it.
    • Make sticker: turn the picture into a sticker.
    • Document: straighten a photographed page as a document.

    Download Image Editing Beta build 0.1.0-beta.17

  • Plugin Working

    Device Link

    • Send Page: send the open page to an iPhone or a Mac over LocalSend.
    • Send Selection: send a lasso selection, as typed text or as a picture; you choose on each send.
    • Receive: receive text, a picture or a PDF into the open note.
    • Editor helper: applies the Ink Notebook Editor's edits from the Mac to the tablet's notes.

    Download Device Link Version 0.1.0

  • Plugin Beta

    Account Sync

    • To-Do: sync the tablet's to-dos with Todoist.
    • Calendar: sync Google, iCloud and ICS calendars with the tablet's calendar.
    • Digest: sync the Digest both ways with your Telegram «Saved Messages». (planned)

    Download Account Sync Beta build 0.1.0-beta.30

  • Plugin In progress

    Puzzles

    • New game: pick a game, a language and a difficulty; the game is a new page after the current one, its grid drawn as the page background, so erasing never removes it.
    • Show solution: shows the answer over the plugin's view, never on the page.
    • Check: reads what you wrote and marks the wrong cells.

  • Tablet app Beta

    Handwriting Language

    • Switch Language: switch the handwriting recognition language of the whole tablet with one tap.
    • Floating button: a small button where you write, shown only while there is text or ink input.

  • Mac app In progress

    Ink Notebook Editor

    • Open a note: read a .note notebook on the Mac and page through it.
    • Open from Tablet: copy a note from the tablet over the cable through inkctl and open the copy.
    • Edit: edit a note on the Mac without breaking the format, and send the edits back through Device Link.

Developer tools

  • Mac command line Working

    Ink Tools Control

    • Control: inkctl controls the tablet over Wi-Fi ADB or USB with direct calls, JSON answers and stable exit codes, without root.
    • Plugins: install, enable, permit and uninstall plugins with no screen.
    • Notes and ink: open notes, write synthetic ink, lasso and read the screen for tests.
    • Firmware watch: on connect, check every device dependency and report what a firmware update broke.

  • Tablet app Internal

    Ink Tools Helper

    • Plugin settings: lets inkctl install, enable and permit plugins with no screen.
    • Firmware watch: at boot after a firmware change, check every device dependency and report what broke.

  • Plugin Internal

    Ink Tools Probe

    • Run Command: the sidebar button inkctl presses to write ink and lasso with no pen.
    • Probes: quick on-device experiments for our tests. Never shipped.

Install in a few minutes

Most people need only a plugin: download its file, copy it to the tablet and install it from Settings. No root, no modified firmware.

Install a plugin

  1. Download the tool's .snplg file with its Download button on inktools.martonpaulo.com, or from its release on the releases page. Keep the file name: it carries the version.
  2. Connect the tablet to the computer with a USB cable, or use Supernote Cloud, and copy the file into the tablet's MyStyle folder.
  3. On the tablet, open Settings, then Apps, then Plugins, and tap Select Plugin Package. In Select Plugin, choose the file, then tap Install.
  4. When the tablet asks, allow the permissions the release notes list. A plugin that is refused a permission shows what it needs and how to give it.
  5. Tap the plugin in the Plugins list to open its page, and turn it on with the switch there. The tablet keeps at most 10 plugins on at one time.

Install the tablet app

Handwriting Language has no release yet: it waits for a build signed with a release key. Until then it installs only from a copy of the repository, over a cable, as its README shows.

Install the Mac app

Ink Notebook Editor is in progress and has no release yet. It builds on a Mac from a copy of the repository, as its README shows.

Install the Mac command line

Ink Tools Control (inkctl) is for developers and has no release: it runs from a copy of the repository.

  1. On the Mac, install Python 3.9 or later and Android's adb tool.
  2. On the tablet, turn on Sideloading in Settings (how).
  3. In Terminal, copy the repository: git clone https://github.com/martonpaulo/ink-tools.
  4. Follow the Quick Start of Ink Tools Control: it puts inkctl on your path and connects it to the tablet.

Before you install

Ink Tools is unofficial. It is not made, affiliated with, endorsed or reviewed by Ratta. «Supernote» is a trademark of its owner and names the device only.

Some tools use parts of the tablet's software that Ratta does not document. A firmware update can change those parts and break a feature until a fix ships. The firmware watch checks those parts after an update and reports what broke.

No tool needs root or modified firmware. Use these tools at your own risk, and keep a backup of your notes before you install or update one.

Built in public, on shared work

A special thank-you to the authors of these Supernote projects. Ink Tools stands on their work: some of their code runs inside it, and some of their ideas shaped it.

  • jya-dev/supernote-tool: the .note reader and RLE decoder, ported to Swift.
  • CharlesCheval/supernote-snap: the Smart Shapes recognizer, hold detection and stroke guard.
  • Keplex/supernote-pic2note: the native build pipeline without Gradle.
  • AgP42/SuperFun: the word-search theme word banks; a set of games inside one plugin.
  • wolfsolver/Supernote-InkGames: puzzles generated for the page, solved with the pen.
  • Laumss/Inkling: write a picture file, then insert it on the page.
  • Laumss/sn-plugins: the Settings screen conventions in ui-kit.
  • ridget/supernote-mcp: inkctl touches the tablet only when it is called.
  • CRSiegfried/inkbridge: inkctl leaves transcription to whoever calls it.

Each project's licence, and what Ink Tools took from it, is in the NOTICE.md of the part that uses it.
