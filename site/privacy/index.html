Privacy policy

Last updated 27 November 2026. Ink Tools runs no server. It collects no analytics, has no account of its own and sells nothing. Each tool below sends data only to the service named, and only when you use that feature.

Account Sync

Account Sync brings your to-dos and calendars onto the tablet. Every account is off until you connect it in the plugin's Settings. The tablet talks to each service directly; nothing passes through a server of ours.

  • Todoist (api.todoist.com): reads your tasks and projects, and sends back the tasks you add, change, complete or delete on the tablet. It uses a Todoist API token you create.
  • Google Calendar (www.googleapis.com, oauth2.googleapis.com): reads the events of the calendars you choose, and sends back the events you add, change or delete on the tablet. It uses a Google sign-in you make on your Mac with inkctl.
  • iCloud Calendar (caldav.icloud.com): reads and writes the events of your iCloud calendars over CalDAV, with your Apple ID and an app-specific password.
  • ICS calendars: reads each calendar feed address you enter. Nothing is sent to it.
  • Telegram (planned, not yet released): the Digest module will sync the tablet's Digest with your own Telegram «Saved Messages» through the official Telegram API, after you sign in. This policy will say exactly what it sends before it ships.

Your tokens and passwords are kept in two places only: in the plugin's private folder on your tablet, and in your Mac's login Keychain when you sign in from the Mac. They are never written to a log or sent anywhere except to the service they belong to.

Google user data

Ink Tools' use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Account Sync reads and writes Google Calendar events only to show them in the tablet's Calendar and to carry your tablet edits back. It does not transfer them to anyone else, does not use them for advertising, and no person reads them. You can remove its access at any time in your Google Account's security settings.

Lasso Actions

When you press a Lasso Actions button, the word you lassoed, as recognised text, is sent to the public service that button uses. Nothing else from your note is sent, and no account is used.

  • Pictures: Wikimedia Commons, Wikidata and Wikipedia (wikimedia.org, wikidata.org, wikipedia.org) and Openclipart (openclipart.org). The built-in emoji set needs no network.
  • Definitions: Wiktionary (wiktionary.org).
  • Summaries: Wikipedia (wikipedia.org).
  • Translations: Apertium (apertium.org).

Each service receives your tablet's network address, as with any web request, and handles it under its own privacy policy.

Device Link

Device Link sends a page, a selection or text to a LocalSend device you pick, and receives from one, only on your local network. It finds devices with LocalSend's discovery on that network and sends over an encrypted connection straight to the device. Nothing goes over the internet.

Language pack downloads

Planned, not yet released. When you choose to add a handwriting language pack, the app downloads it from GitHub Releases (github.com). Only the request for the file is sent; GitHub sees your network address, as with any web request, and handles it under its own privacy policy. Nothing is downloaded until you ask. To remove a pack, delete it in the app's language list.

Supernote Cloud password

This feature is planned and not yet released. Note Editor can reach your notes through Supernote Cloud, only if you connect it in Settings. Your Supernote Cloud password is sent to Supernote's own service to sign in and is kept in your Mac's login Keychain, never in a file or a log. To remove it, disconnect Supernote Cloud in Settings, or delete the item in Keychain Access.

Browse & Access

This mode is planned and not yet released. Browse & Access is the Supernote's own feature that serves your files over your local network. Note Editor reads your notes from it over plain HTTP, with no password and no encryption, so anyone on the same network can read what it sends. Use it only on a network you trust. It is off until you turn it on in the tablet's settings and choose it in Note Editor's Settings; turn it off on the tablet to remove access.

Sign-in token sent through Device Link

This step is planned and not yet released. You can sign in to Account Sync on your phone and send the sign-in token to the tablet as text through Device Link. The token travels over your local network on LocalSend's encrypted connection, straight to the tablet, and is stored in the plugin's private folder like any other token. To remove it, disconnect that account in Account Sync's Settings.

Ink Tools Probe

Ink Tools Probe is a developer tool for testing Ink Tools on a tablet; it is never released to users. It holds the network permission only so that a test can try a network call. It sends no data of yours to any service, and writes its results to the tablet's own log.

Tools that use no network

  • Image Editing and Smart Pen work on the tablet only and have no network permission.
  • Handwriting Language only changes the tablet's own recognition language setting.
  • Note Editor and inkctl run on your Mac and talk only to your tablet, over USB or your local network. inkctl also makes the Google sign-in with Google when you ask it to.

This website

This site is a set of static pages served by GitHub Pages. It uses no cookies, no script and no analytics. GitHub may keep its own server logs under the GitHub Privacy Statement.

Contact

For a question about this policy, or to report a problem, open an issue on GitHub. Changes to this policy are made in the public repository, so every earlier version stays visible.
